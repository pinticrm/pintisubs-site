# PintiSubs Studio — Public Website

Bu depo **yalnızca** PintiSubs tanıtım sitesinin statik HTML/CSS/JS içeriğini ve Windows önizleme sürümünü (GitHub Releases) barındırır. Özel çeviri arşivleri, ekran görüntüleri, günlükler, API anahtarları veya kullanıcı kayıtları içermez.

Site: https://pinticrm.github.io/pintisubs-site/

## Yayın

GitHub Pages: **Deploy from a branch** → `main` → `/ (root)`. `.nojekyll` eklidir.

API, ayrı Ubuntu sunucusunda barındırılır. Yönetici paneli ve kullanıcı bildirimleri **bu depoda değildir**; bunlar sunucu üzerindeki HTTPS servisidir.

Windows `v5.1-preview` sürümü bir önizlemedir. Gerçek oyun uyumu ve arayüz testleri devam etmektedir. Resmî oyun yayıncısı ürünü değildir.

## Lisans / veri

Site kaynakları için telif hakkı PintiSubs proje sahibine aittir. Oyun içi metinlerin veya özel arşivlerin dağıtımı bu depoya dahil değildir.
