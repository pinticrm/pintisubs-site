# PintiSubs 0.1 — tanıtım sitesi

Canlı adres: https://pinticrm.github.io/pintisubs-site/

Bu açık GitHub Pages deposu **yalnız tanıtım, TV bağlantı rehberi ve gizlilik metinlerini** içerir. Kullanıcıların API/PSN kimlik bilgilerini veya oyun ekran görüntülerini toplamaz. Eski 8 haneli sunucu eşleştirmesi 0.1 sitesinden kaldırılmıştır.

## Yayın disiplini

- Windows Studio önizlemesi ve Android TV katmanı **geliştirme** statüsündedir.
- İmzalı ve herkesçe indirilebilen bir GitHub Release henüz doğrulanmadı; sitede sahte İndir düğmesi yoktur.
- Android TV HDMI üstü altyazı OEM/firmware bağımlıdır. OBS tarayıcı katmanı alternatif olarak anlatılır.
- iPhone TestFlight, native LG/Samsung TV paketleri, yerleşik PS5/Xbox Remote Play bu sitede hazır özellik olarak gösterilmez.

Dosyalar: `index.html`, `assets/site.css`, `eslestir/index.html`, `privacy.html`.

Kaynak geliştirme: `pinticrm/pintisubs` özel beta deposu; yalnız yetkili geliştiriciler görebilir. Dış kullanıcı için indirme sayfası, gerçek public Release eklendiğinde güncellenmelidir.

## Kontroller

Statik HTML: gezinti/relative link, mobil 360px+ responsive, klavye odak görünürlüğü, erişilebilir başlık, yerel bağlantı güvenliği ve indirme iddiaları. GitHub Pages dağıtımının canlı erişimi ayrıca test edilmelidir.
